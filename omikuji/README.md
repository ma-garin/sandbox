# omikuji — おみくじ帳

引いたおみくじと参拝を記録して読み返すための PWA。スマホでの利用が前提。

公開先: https://ma-garin.github.io/sandbox/

## 何が入っているか

| 場所 | 内容 |
|---|---|
| `app/` | 公開されるアプリ本体。GitHub Pages にはこの中だけが載る |
| `app/data/omikuji.json` | 写真から書き起こした過去の記録 33 件 |
| `data/` | おみくじ写真の原本 38 枚（**リポジトリには含めない**。`.gitignore` 済み） |

## 画面

| タブ | 中身 |
|---|---|
| **TOP** | 参拝カレンダー（月表示・祝日つき。お参りした日に寺社名の札が乗る）／直近3件／訪問記録（寺社別の回数） |
| **訪問記録** | 日付・時間・場所・目的・おみくじ・賽銭額・購入品・メモを一覧 |
| **おみくじ** | 検索・吉凶と種別の絞り込み・年で区切った全記録 |
| **設定** | 記録の書き出し／読み込み（JSON）・隠した記録・件数の数え上げ |

記録は右下の＋から足す。カードや日を押すと詳細が全画面で開き、前後送りで隣の回へ移れる。

**カレンダーとおみくじの分担**: カレンダーは「いつ・どこへお参りしたか」だけを扱い、吉凶や本文は「おみくじ」タブが持つ。月に1回の参拝を日付マスに置くと大半が空白になるが、続いていること自体が見えるほうを取った。

訪問記録の行を押すと、その寺社で一覧が絞り込まれる。

## 記録できること

おみくじの型を10種用意してある。選ぶと寺社名と判断の項目名が入る。

| 出どころ | 型 |
|---|---|
| この帳面の写真から起こしたもの | 東京大神宮 恋みくじ／同 縁結びみくじ／出雲大社 東京分祠／神田明神／明治神宮 大御心／櫛田神社／天満宮／運勢みくじ |
| 一般形 | 元三大師百籤（観音百籤）系の13項目／型を選ばず自由に書く |

番号は第一番〜第百番から選べる。「第11番」「第三〇番」のような書き方は自由記入で受ける。

参拝そのものの記録として、時間・目的・賽銭額・購入品・メモも残せる。

## 調べたこと

PWA の UI/UX について 34 記事を読んだ結果を [`docs/PWA-RESEARCH.md`](docs/PWA-RESEARCH.md) に残してある。
数値を伴う指針、対応済み／未対応、**引用してはいけない数値**（一次確認できなかったもの）まで書いてあるので、同じ調査を繰り返さないこと。

## 確かでないところ

そのまま信じてよいわけではない箇所を、データ側に印を付けてある。

- **日付が推定** 2 件（`dateEstimated: true`）— EXIF が除去されていたため、IMG の連番位置から補間した
- **神社名が推定** 21 件（`shrineInferred: true`）— 上記の根拠による。詳細画面の「この記録について」に理由を出している
- **本文を読み取れず** 数件（`confidence: "medium"` / `"low"`）— 印字が薄い、逆光など。該当箇所は「読み取れず」と表示される

## 動かす

ビルドは要らない。`app/` を静的配信するだけ。

```sh
cd omikuji/app
python3 -m http.server 8765
# http://localhost:8765/
```

ES modules と Service Worker を使うため、`file://` では動かない。必ず HTTP で開く。

## 公開

`main` に push すると `.github/workflows/omikuji.yml` が走り、`omikuji/app` がそのまま Pages へ出る。
デプロイ前に記録データの形式（id の重複、date と type の有無）と参照ファイルの存在を確認している。

## 写真の扱い

アプリは本文テキストだけを表示する。写真は表示しない。
原本は `data/` に置いたままにし、リポジトリには入れない（合計 80MB 超のため）。
どの写真から起こしたかは各記録の `sourcePhotos` に控えてあり、詳細画面の末尾で確認できる。
