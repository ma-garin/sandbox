実行の詳細

画面で使う

  1. 「文書の作成」で入力の種類を選び、GitHub の URL・.zip ファイル・フォルダのパスのどれかを入れます。
  2. 文書の種類と出力形式を選び、「文書を作る」を押します。
  3. 終わると「結果」に文書の一覧が出ます。HTML はこの画面で閲覧でき、各形式をダウンロードできます。
  4. 入力・設定・処理時間・ファイル件数・LLM の使用量は「実行記録」で確かめられます。

コマンドで使う

同じ処理をコマンドでも実行できます。使い方は node src/cli.ts --help で表示します。

node src/cli.ts --folder ./my-app --docs D01,D03 --format md,html

文書の根拠

各記述には「事実」「推測」「不明」のどれかを付けています。「不明」の項目は D09 確認事項一覧にまとまっています。
