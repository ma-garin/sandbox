## このプロジェクトの概要

ソースコード（GitHub / ローカル）からリバースエンジニアリングで仕様書などを生成する、モダナイゼーション・マイグレーション支援ツール。

## 対象ファイル

```
Spec2Doc/
├── README.md
├── AGENTS.md
└── CURRENT_STATE.md
```

## 対象外ファイル

- `sandbox/` 配下の他プロジェクト（フォルダ間の依存禁止）

## 使用技術・制約

- 未定（要件定義で決める）
- 解析対象のソースコードに含まれる秘密情報（`.env`・鍵・接続文字列）は出力ドキュメントに転記しない
