# 仕様 ⇔ 実装 差分表

Warikan仕様書 Ver.1.0（iOS/iPadOS ネイティブアプリ）を Django の Web アプリとして
実装するにあたり、**そのまま写像できなかった箇所**を記録する。

システムテストの計画時は、この表の「差分あり」行を**テスト対象外**または
**代替手段での確認**として扱うこと。

凡例：◎ 同等に実装 ／ △ 代替実装（挙動が異なる）／ × 未実装

| 3.2 戻るボタン（タイトルバー左） | `templates/warikan/base.html` の `backbutton` ブロック | ◎ | ジャスPay・登録・履歴の3画面に表示。 |
