# docready-triage

> 本ファイルは仮置き。正式版の作成は引き継ぎタスク5（README.md の作成）で行う。

## 概要

社内文書をAIエージェントに渡す前に、「そのまま変換していいか」を判定し、
AIに添える構造説明文と、エージェントが最初に読む索引（目次）を生成するツール。

「ExcelやPDFを `.md` に変換すればAIが読みやすくなる」という通説は実証研究では支持されない。
特に結合セル・多階層ヘッダはMarkdown記法で表現できず、変換した時点で構造情報が消える。
本ツールは最適化ではなく、情報が消える変換を避けるための足切りとして設計されている。

## セットアップ

不要。`docready-triage.html` をブラウザで開くだけで動く。
外部依存は Google Fonts のみ、ビルド工程なし。

## 使い方

1. `docready-triage.html` をブラウザで開く
2. 「判定する」タブで文書の種別とチェック項目を入力し、判定結果（ok / warn / risk）を得る
3. 「文書棚卸し」タブで対象文書を登録する
4. 「索引を出力」タブで索引（目次）を出力する
5. 「根拠」タブで各判定ルールの出典を確認する

状態はメモリ保持のみ。作業を残す場合は JSON で手動保存し、次回は手動で読み込む。
